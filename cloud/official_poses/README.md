# 官方动作库

云端对外发布的动作。电脑端只自带原地踏步和小腿向后抬起，这里的动作要从云端下载才有。

每个 `.json` 是一个动作：名字、怎么做、火柴人示范、星级、会扫过哪些跟随区域，以及**识别规则**。
识别规则是数据，由 `motioncontrol_shared/pose_rules.py` 解释，不是代码——下载回来的东西只能拿
关节坐标比大小、算距离和角度，碰不到文件和网络。

## 发布一个动作

1. 在这里改或加一个 `.json`。改了内容就把 `revision` 加 1，电脑端据此提示"有新版本"。
2. 跑测试：`python -m pytest tests/test_pose_rules.py tests/test_pose_library.py -q`。
   示范图里"做到位"的那一帧必须能被它自己的规则认出来，起始姿势不能。
3. 签名：`python tools/sign_pose_library.py`。用的是和软件更新、手机网页包同一把私钥
   （`config/phone_web_signing_key.txt`，不进仓库）。签名写进 `signatures.json`。
4. 部署云端。

**没签名、或者改了内容没重新签名的动作，云端不会发布。**电脑端也只装验得过签名的。

## 字段

| 字段 | 说明 |
|---|---|
| `id` | 触发名是 `motion.<id>` 或 `pose.<id>`，发出去就不要改，别人的配置靠它引用 |
| `revision` | 第几版，从 1 开始 |
| `group` | `motion`（身体动作）或 `pose`（姿势） |
| `ratings` | 运动强度 `intensity`、识别度 `recognition`、上手难度 `difficulty`，各 1~5 星 |
| `body_parts` | 腿部 `legs`、臀部 `glutes`、核心 `core`、手臂 `arms`、肩背 `shoulders`，只写用得上的，各 1~5 星 |
| `passes_zones` | 做的时候身体会经过的跟随区域。只在用户没「录我的动作」录过这个动作时兜底，录过的按录的算。`sweeps_first` 已经不用了，旧文件带着也不报错 |
| `debounce` | `[按下要连续几帧成立, 松开要连续几帧不成立]` |
| `risk_timing` | 身体动作才有：给头控防误触用的 `[认定要多少秒, 放下要多少秒]` |
| `blocks_steps` | 做着这个动作时不算踏步、不算小腿后抬（下蹲） |
| `claims_lift` | 一次抬腿碰上了这个动作就只算它，不算踏步（提膝碰对侧肘）；规则必须 `sides` |
| `demo` | 示范：`frame_s` 每帧几秒，`frames` 每帧 13 个点的画面坐标（x 向右、y 向下，没镜像） |
| `rule` | 识别规则，写法见 `pose_rules.py` 的说明 |

## 门槛是怎么来的

这些数字是 2026-09 用真人录像回放调出来的，改之前先想清楚。

- **下蹲**：两个膝角都弯过 145°，且膝盖比胯低不到 0.84 个躯干。录像里浅蹲到 133°/137°，
  站着 165° 以上；以前用 135°，浅蹲认不出。
- **双手举过头**：两只手腕都高过鼻子 0.06 个躯干，两个手肘抬到肩附近以上。试过换成录制
  模板（只比手臂方向），6 次只认出 1 次——举手时手肘是弯的，每个人弯法不一样；这条规则
  6 次全认出，单手举不算。
- **开合跳、侧步开合**：两脚分开到肩宽的 1.0 倍。录像里跳开时 1.05~1.46，站着 0.6~0.8；
  以前用 1.42，大多认不出。手举过肩 0.28 个躯干以上是开合跳，两手往两边伸开（手腕间距
  超过肩宽 1.72 倍）且不举过头是侧步开合。
- **提膝碰对侧肘**：抬起的膝盖和对侧手肘靠到 0.95 个躯干以内。录像里真碰的那几下在
  0.37~0.88，旧的 0.72 漏掉一半。`attempt` 多留 0.18：明显在往对侧肘靠、还没碰到的那一下
  抬腿，不要在脚踝到最高时误算成踏步；普通踏步手肘离膝更远。不看手腕和脚踝——做的时候
  那两个常被挡住，抬起的膝盖和对侧手肘却看得清。
- **双手交叉**：两只小臂在胸前交叉成 X。真人录像里交叉点附近手腕常被认错边、被挡住，所以
  看的是"小臂往里指 + 交叉顺序 + 在胸前"，不要求手腕深深过到对侧。

## 星级

星级是给人挑动作用的，不影响识别。现在的数是按动作本身估的初值：识别度参考上面的录像回放
（举手 6/6 最稳，提膝碰肘和双手交叉常有遮挡），运动强度和部位按常见的健身说法。有了更多真人
数据再调。
