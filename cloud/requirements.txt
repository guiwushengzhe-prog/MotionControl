# Cloud service dependencies, pinned.

# The desktop app deliberately has no framework -- it has to run on a player's
# machine with no pip. That constraint does not apply here: this runs on one
# server we control, so the cost of FastAPI is a dependency file and the
# benefit is dependency-injected auth, request validation and body-size caps
# that would otherwise be hand-rolled.
