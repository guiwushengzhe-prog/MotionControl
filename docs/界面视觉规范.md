# 界面视觉规范

## 共享外观

- 所有页面从 `web/app.css` 的共享变量取色，不在新模块另配背景、蓝色或字体。深色与浅色外观共用组件规则，自动外观与手动外观保持一致。
- 背景、卡片、控件分成三个柔和层级；卡片、列表和输入控件使用统一的细边框与圆角。避免把每个设置项做成不同颜色的大色块。
- 蓝色用于主要操作、可操作链接、滑条与已开启的开关；绿色用于识别成功与已就绪，橙色用于提醒，红色用于删除和错误。导航选中项使用中性的灰色底和明确文字层级。
- 字体沿用系统字体。页面标题、分组标题、项目名称、辅助说明按固定层级区分；项目名称略加粗，说明用次要文字色，长说明自然换行。

## 设置排布

- 保留左侧分类导航的原宽度和宽松布局，不因分类较少而压缩。窄屏改为横向分类栏。
- 右侧统一使用分组标题与列表卡片，分隔线两端等距缩进。设置名称和说明放在左侧，操作放在右侧。
- 下拉框、普通文本输入和滑条复用同一控件列宽；含附加按钮的设置行共享这列总宽。开关在右侧对齐，滑条数值使用等宽数字并靠右排列。
- 文字变长时优先换行，不能压住操作控件。窄屏时操作移到下一行，名称与开关仍保持一行，页面不得横向溢出。
- 新模块先复用现有的 `.group`、`.list`、`.row`、`.row-main`、`.sub`、`.sel` 与 `.range-in`，特殊图表和预览只扩展必要部分。
