# 界面视觉规范

## 共享外观

- 所有页面从 `web/app.css` 的共享变量取色，不在新模块另配背景、蓝色或字体。深色与浅色外观共用组件规则，自动外观与手动外观保持一致。
- 背景、卡片、控件分成三个柔和层级；卡片、列表和输入控件使用统一的细边框与圆角。避免把每个设置项做成不同颜色的大色块。
- 浅色外观使用干净白底，白色分组由轻边框与柔和阴影区分，输入控件用浅灰；深色外观保留同一布局和层级，不单独复制一套组件。
- 蓝色集中于首页主要控制、滑条与已开启的开关。设置里的按钮、链接、提示框和焦点边框使用灰色层级，避免蓝色字、蓝色边框和橙色提示块；提醒用明确文字表达。导航选中项使用中性的灰色底和明确文字层级。
- 动作库的静态键位、添加映射、等级点阵与删除入口使用中性色；真实动作触发继续使用语义反馈色，删除操作在悬停或确认时强调。不得把“已绑定”当成正在触发而铺绿色。
- 字体沿用系统字体；字号与字重统一从共享文字变量读取，说明使用次要文字色，长说明自然换行。

## 标题与文字层级

以16像素根字号为例，实际尺寸跟随已有的全局缩放；深浅两种外观共用同一套层级。

| 层级 | 用途 | 字号 | 字重 | 颜色 |
|---|---|---|---|---|
| 一级 | 页面名称，例如“体感”“本游戏” | 1.5倍根字号，24像素 | 650 | 主要文字色 |
| 二级 | 大分组，例如“游戏输出”“身体识别” | 1.0625倍根字号，17像素 | 600 | 主要文字色 |
| 三级 | 子分组或卡片名称，例如“识别模型”“摄像头” | 0.9375倍根字号，15像素 | 600 | 主要文字色 |
| 设置项 | 具体设置名称、输入内容、按钮 | 0.875倍根字号，14像素 | 正文400；操作按钮可用500 | 主要文字色 |
| 辅助说明 | 操作说明、状态补充、字段说明 | 0.8125倍根字号，13像素 | 400 | 次要文字色 |

- 页面、大分组、子分组分别使用一级、二级、三级标题；不能通过把设置名称普遍加粗来代替标题层级。
- `.pane-title`、页面标题、`.group-title`、`.settings-section-title`、卡片标题和折叠标题共用对应字号与字重变量。新页面复用这些角色，不另定一套文字尺寸。
- 关键指标与摄像头画面中的实时提示可以使用展示字号，普通表单仍遵循上述层级；错误、警告和真实触发保留原有语义色。

## 分组与分隔

- 同一功能组的设置项用留白组织，不逐行添加小横线；子组标题下的项目增加一级缩进，名称与控件仍保持对应。
- 大卡片的外边界、不同功能块之间的分隔保留；映射条目、历史记录与独立诊断模块按记录边界分隔。
- 体感子组、设备详细设置和运动资料表单统一使用共享缩进；展开内容沿用所在层级，不为每个子项再套一张卡片。
- 诊断模块内部的名称和值以排布区分，不在每个字段下画横线。曲线和数据图中的网格属于图表，不作为表单分隔使用。

## 设置排布

- 保留左侧分类导航的原宽度和宽松布局，直接排在页面底色上，不加外框或整块背景；选中项保留中性底色。窄屏改为横向分类栏。
- 设置页的外层随窗口扩展，两侧保留适度边距；左侧导航贴近页面起点，右侧内容最多占58倍根字号，在导航之外的可用区域内居中，避免名称和控件被拉到屏幕两端。顶栏和状态提示沿用外层边距，窄屏内容自然铺满。
- 开始与本游戏使用同一内容宽度：外层最多72倍根字号，扣除边距后的内容最多69倍根字号；对应顶栏及状态提示与内容对齐。预览与状态、动作与选键保持靠近，缩小窗口时自然收缩。
- 右侧统一使用分组标题与列表卡片，设置名称和说明放在左侧，操作放在右侧；分隔遵循功能层级，不由列表自动给每个子项画线。
- 语音和宏按大类共用一张列表卡片，标题在卡片外；组内用宽松设置行和统一边距组织内容，通用口令等子分组增加缩进，避免为唤醒词、急停、每条口令或宏再叠独立卡片。
- 体感归为“游戏输出、视角控制、身体识别”三个大分组，组内设置共享卡片；当前状态、选中方式及保存回执继续保留。录制与直播在桌面优先展示预览、常用画面与声音设置、录制按钮及直播地址入口，保留足够行距与预览高度；较小窗口允许自然滚动。人物细节与接入说明默认收起；下方两张折叠卡片与上方预览、常用设置分别共用列宽及间距。缩小窗口后自然分行，预览保持实际比例。
- 下拉框、普通文本输入和滑条复用同一控件列宽；含附加按钮的设置行共享这列总宽。开关在右侧对齐，滑条数值使用等宽数字并靠右排列。
- 文字变长时优先换行，不能压住操作控件。窄屏时操作移到下一行，名称与开关仍保持一行，页面不得横向溢出。
- 新模块先复用现有的 `.group`、`.list`、`.row`、`.row-main`、`.sub`、`.sel` 与 `.range-in`，特殊图表和预览只扩展必要部分。
- 设备使用宽松的大卡片，与设置列表共用底色、边框、圆角和阴影规则。顶部显示名称和连接状态，中部显示实际设备与三项关键数据，常用操作直接可用；详细设置通过底部统一下拉箭头原位展开。数据复用已有状态更新，不为卡片另加设备轮询。运动记录按“运动、身体与设备、数据同步”组成少量大组，组内列表行共享背景和分隔线，摘要与详细内容分层展示。

## 逐页布局打磨

- 共享层级规定字体、颜色和组件外观；各页的内容宽度、操作位置、留白与卡片组合按实际任务逐处调整。
- 设备页突出连接状态、关键数据和常用操作；体感页重点检查设置名称与控件的距离；录制页在预览和常用设置之间保留舒展的操作空间，主要操作优先展示；运动记录先展示活动结果，再展开资料和连接设置。
- 每次局部调整都检查整页视觉：主次是否清楚、相关内容是否靠近、上下边界是否对齐、深浅外观和窄窗口是否协调。统一文字层级不代表各页布局已经完成。
- 保留用户已经确认的宽松导航、设置内容居中、设备大卡片及默认折叠；局部打磨沿用共享规则，不通过另建字体或色块制造区别。

## 数据可读性

- 中文诊断沿用界面字体，不整段使用程序代码字体；数字使用等宽数字对齐。帧率、延迟和处理器占用先展示主要数值，细节按模块展开，用名称和值分列，保留原始数据含义。
- 运动记录先展示本次活动、今日目标与最近历史。身体数据与目标编辑、手环连接等设置可展开；历史日期和分钟、步数、热量分别对齐。展示调整不改变活动累计、历史计入或热量估算规则。
