## 使用
网页“游戏输出→物理手柄合流”明确选择物理手柄。选择后使用现有同一个虚拟 Xbox 360；原始按钮、双摇杆和双扳机整帧透传。开启输出只开启体感按钮层；配置动作类型为手柄按钮，目标可填写 A 或 LB+A。合流时忽略体感键鼠、摇杆和扳机映射。

关闭体感输出、急停或姿态超时均保留物理透传；关闭合流则停止物理透传。配置仅本次服务有效，重启需重新选择物理手柄。物理设备断开不会自动切换到其他槽位。
