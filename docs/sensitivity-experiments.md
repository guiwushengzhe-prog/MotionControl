# 灵敏度实验

入口：设置 → 实验与诊断 → 灵敏度实验。四项默认关闭，保存后记住；开启实验不自动启动识别、控制输出或录制。

| 开关 | 生效范围与行为 |
|---|---|
| 偏头持续转向 | 先选择“左右转头（模型·简化回正）”。开启后偏头保持时持续同向转向，回正时速度减小，进入实际死区停止。沿用同一模型、校准、滤波、速度与曲线，不增加回正锁；关闭恢复原简化版。 |
| 首步响应 | 只作用于“灵敏踏步”。可信单脚抬起确认后即可短时前进，不等待另一只脚；交替踏步维持前进，保留落地停止、双脚起跳及其他动作排除。 |
| 身体侧倾走位 | 人物左倾、右倾分别持续触发“身体左倾”“身体右倾”，回正停止。 |
| 身体后倾后退 | 人物向远离相机的方向后倾触发“身体后倾”，回正停止。有效后退绑定会暂停踏步前进；横向可与前后组合。 |

## 模型估计与深度实测

来源选择同时用于首步与身体倾斜实验。两路可以显示对照，只有选定来源输出；手选深度而没有可靠深度数据时停止对应实验，不暗中换成模型数据。

- 模型侧倾读取未融合深度的原始二维肩髋；模型后倾读取同帧模型估计的三维肩髋，不要求深度设备。
- 深度来源读取已与当前人物可靠匹配的原生三维骨骼。它是可选测试来源，普通摄像头路径独立运行。
- 模型、深度分别保存中立站姿；首次开启或“重设站姿”时自然站直约一秒。相机位置、朝向变化后应重设。部分数据不可用只暂停对应方向：例如缺少三维时，可靠二维侧倾仍可工作。
- 首步的原始脚部信号也分别建立站稳基准，不能混用模型与深度单位。原有动作冲突与输出仍走统一控制链。
- 首帧、切换来源和失帧恢复先建立静默起点。过期超过0.25秒的输入不用于新的身体实验输出。

侧倾起动/松开阈值初设6°/4°，后倾7°/5°，用于实验比较，不宣称已经为用户真人优化。模型三维数据可能不稳定，深度接口也可能未取得当前人物；界面显示实际有效性、校准情况和两路读数。

## 游戏绑定

“本游戏”提供“身体左倾”“身体右倾”“身体后倾”三个动作。已有自定义绑定或明确禁用优先；明确前进绑定为W、方向键上或左摇杆上时，可以派生对应左右与后退默认方向。其他特殊前进键位不猜方向，需要自行选择。原小腿后抬、脚部技能框的绑定保留。

## 诊断录制与验证边界

触发录制可多选，按下多个动作选择会保存完整集合。增强录制保留实际原始模型/深度/头部结果、实验配置和中立站姿，用于同段离线回放；没有图像不能重新运行另一套图像模型。旧录制缺少的字段不会凭空补造。

合成角度、骨骼和隔离网页检查验证的是判定、接线、保存及恢复，不代表真人手感或游戏延迟验收。只有用户实际开启实验、使用并录到对应数据后，才能比较具体体验。
