# 电脑端测试

用已安装运行依赖、pytest（测试框架）和 Playwright（浏览器测试工具）的 Python 环境。
在工作目录执行：

```powershell
$env:MOTIONCONTROL_USER_DIR = Join-Path $env:TEMP 'MotionControl-Test-User'
python -m pytest -q -rs -p no:cacheprovider --vosk-model="中文语音模型目录" tests
```

中文语音模型是 `vosk-model-small-cn-0.22` 的解压目录。`--vosk-model` 只供两项真实语音模型测试使用，不会让其他模拟测试加载模型。已经把模型安装到本工作目录的 `models/vosk-model-small-cn-0.22` 时可省略这个参数。缺少模型或依赖会明确失败，避免遗漏真实模型检查。

测试自动给每项检查创建独立用户资料；浏览器测试使用随机端口，并在完成后关闭自己的服务。
测试结果不能替代真人动作、游戏控制或跨设备验收。

冻结头控参考的少量真实帧和独立预期值已经包含在 `tests/fixtures`，常规测试无需外部资料。
需要回放完整审核归档时，另设：

```powershell
$env:MOTIONCONTROL_FROZEN22_ROOT = '审核归档的 expanded 目录'
```

## 云端检查分组

按需在 GitHub 的操作页面选择 `runtime-tests` 手动运行；推送代码和创建合并请求不再自动触发这组检查。

电脑逻辑任务在 Windows 和 Linux 上运行，不加载浏览器检查文件。浏览器任务安装完整组件后运行网页、录制、区域编辑、心率和真实本机接口检查；不再让缺少浏览器组件导致逻辑任务在收集阶段中断。云端服务检查独立运行。

真实中文语音模型由 `tools/prepare_ci_voice_model.py` 从官方来源准备并缓存，使用 `--vosk-model` 只传给指定的两项真实模型检查；不通过全局语音模型环境变量影响模拟检查。界面中的身体模型选择使用隔离的模型目录占位文件，仅核对选择、保存和重开，不运行推理或读取个人模型。

测试用的动作与区域需要明确配置有效绑定；空绑定继续不输出。折叠栏目应先通过页面入口展开后再操作。视频编码、配置保存等异步步骤等待实际完成条件，不用固定短延时作为成功依据。
