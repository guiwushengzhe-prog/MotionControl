# 2.3.0 协调与性能优化

本次保持既有界面和识别模型，集中修复配置、输入会话、异步任务和实时路径。

本文记录第一轮协调改动；追加的 PC 快照、Android Worker、云缓存、前端变化更新及各项验证边界见[完整优化进度与维护入口](optimization-progress.md)。版本继续保持 2.3.0，实机、兼容与长时间稳定性专项后置。

## 行为约定

- 视角两轴用 `POST /api/view-control` 一次提交，返回 `config_revision`。验证或写盘失败保持原配置；两个文件的恢复记录在启动时处理。
- 游戏方案、映射、动作及自建游戏更改共用配置事务。身体与语音消费者使用同一份已提交绑定；失败时恢复文件与内存。手机配置快照和排队系统操作等待事务完成。
- 显式停止身体输入关闭姿态接收。第一台手机保持身体控制权，断线或过期后才交接；同设备重连淘汰旧连接，序号从新会话重新计数。
- 系统操作按顺序进入有界队列。急停先失效队列并释放输出，再清理校准和录制倒计时；最终提交复查命令和语音会话代次。
- 摄像头、手机音频和本地麦克风分别管理生命周期；迟到结果不能恢复旧会话。手机音频队列最多 8 帧，超过 500ms 的输入丢弃并重置识别连续性。
- 姿态与传感器热路径可跳过完整状态构建；可信采样时间用于平滑与动作消抖。录制使用独立快照在后台原子保存。
- 界面隐藏时停止画布和列表重绘；配置草稿先保存，乱序响应不覆盖新状态。高 DPI 画布限制尺寸，窄屏和触屏保持可操作。
- 云列表批量查询作者、游戏和版本，1、30、100 条结果都最多 4 次 SELECT，不加载版本正文。
- 更新按 hash 复用完整文件，流式下载、有限重试、总预算和退出取消。发布装配要求明确手机 dist 路径，校验两仓库源码与产物 hash 并记录来源。

## 验证

```bash
MOTIONCONTROL_USER_DIR=/tmp/motioncontrol-tests python -m pytest tests cloud/tests -q
python -m pytest tests/test_web_optimization.py -q
```

浏览器测试需要 Playwright 和 Chromium。新增 CI 分别运行 Windows/Linux 逻辑、云 API 和实际 Chromium 行为回归。模拟设备覆盖迟到帧、重连、写盘失败、急停与异步竞争；它们不能代替 Windows 驱动、摄像头和真实游戏验证。

合成 30Hz、关闭持久化与录制的 2,000 帧处理不再生成逐帧状态（2,000→0 次）。首轮 Python 平均耗时 1.170→0.704ms，p95 1.484→0.946ms；共享机器的重复轮次有明显波动，这些数值不表示实机 FPS、耗电或温升收益。

### 追加：通用设置的待保存状态与自行恢复

将通用设置从“忽略写盘异常”接入有效副本、可恢复事务和最多四次的退避重试。实时识别继续使用已应用配置；失败时保存最新快照并通过接口和中性提示显示未保存状态，支持手动重试。自动保存草稿凭同一后台的保存回执完成，拦截旧响应与后台重启造成的假成功。设置损坏且无有效副本时保留原件，明确确认保存当前设置后归档原件；主件丢失且备份损坏也保留剩余原文。

保存事务同时覆盖视角双轴、区域更新的副本与待保存状态。相关后台与启动检查 88 项通过，浏览器检查 32 项通过，之后补测了仅存损坏备份的保留和后台重启后草稿重试。另用真实 Windows 文件共享锁阻止隔离配置替换，验证接口如实报告未保存、解除锁后保存成功，原用户配置内容保持完整。个人故障注入与运行记录继续保存在忽略目录中。

### 追加：换游戏入口与启动时的配置一致性

用户报告正式入口的换游戏列表搜索不到原自建游戏。实际核对确认：磁盘保留自建游戏及原绑定，运行中的同目录后台却返回零个自建游戏。启动复用只核对目录与就绪状态不足以证明已经载入正确版本和配置。

启动前使用统一用户目录读取完整游戏配置版本，并计算不依赖发行版本号的代码内容标识；健康接口保留后台启动时加载的代码标识。复用时同时核对程序、规范化数据目录、代码和完整配置版本，目录联接的旧路径视为同一实际目录。发现旧状态且游戏输出已暂停时，仅请求已识别后台正常退出，等待原进程结束后再启动；控制仍开启时提示先暂停，退出失败时不强制结束或另起争用端口。批处理入口转发启动参数，提供不打开浏览器的实际入口核对方式。

顶栏游戏名称直接展开本游戏页的换游戏面板并聚焦搜索，与原换游戏按钮共用展开入口和状态。相关检查通过；另复制原配置至隔离目录，用正式解释器启动后台并在真实浏览器中搜索、选中原自建游戏，确认只有一个搜索结果且 19 条原绑定完整，原配置内容未改变。私人配置副本与运行记录不提交。
