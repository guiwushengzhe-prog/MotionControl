# 飞鼠甩拳

## 统一入口

“设置 → 设备 → 枪型飞鼠”选择 Windows 已配对的设备，可开关拳击模式，调节触发强度和冷却时间。设备仅在启用且已选择时连接，不扫描正在使用的鼠标，也不读取连续惯性数据。

按键在“本游戏”的原动作映射中设置。动作编号为 `motion.gunmouse_punch`，名称“飞鼠甩拳”，沿用原输出类型下拉框、选键控件、游戏和模式存储；设备设置中的“设置按键”只跳转到同一行。支持键盘、鼠标按键、滚轮及手柄按键、扳机、左摇杆方向，一次甩动点按一次，不提供持续按住或系统功能绕过总开关。新动作默认不绑定。

设备参数存入统一用户目录下的通用设置，沿用有效副本、保存回执和失败补存；包含在同机完整备份内，不把设备地址同步给其他电脑。按键仍属于游戏配置，可与普通游戏配置一同迁移。关闭总输出、不绑定、解绑或换模式后均不补发旧动作。断线及设备停用只释放飞鼠贡献的输出，不清理身体、语音或物理鼠标。

调整强度和冷却就地写入设备，并用新配置代号隔离旧通知，不为滑条断开、重连鼠标。更换设备或关闭拳击模式才结束对应的管理连接。

## 固件接口

现有3.2.6只有状态读取，没有独立甩拳通知。电脑端检查接口是否存在；旧固件显示需要更新，原鼠标功能保留。新接口在现有加密管理服务中追加两个特征，不变更原鼠标报告、采样频率、常开模式、摇杆状态或原校准存储。

- 事件：`a38b0006-62da-4c13-9f07-908d8b921571`，20字节通知，按小端序排列：版本和类型各1字节，就绪标志2字节，启动代号、动作序号、设备毫秒各4字节，触发强度和本次配置代号各2字节。类型0为心跳，1为甩拳。就绪标志的最低位表示传感器有效，次低位表示拳击模式有效。
- 参数：`a38b0007-62da-4c13-9f07-908d8b921571`，8字节加密读写：版本和开关各1字节，强度、冷却毫秒、本次配置代号各2字节。强度范围1300至3000，单位为千分之一倍重力；冷却250至2000毫秒。参数由电脑保存，固件运行时应用，不新增逐次闪存写入。

握稳150毫秒后解锁；加速度达到设置强度且角速度至少每秒80度，连续12毫秒才触发。触发后须经过冷却且重新静稳，回弹和持续大幅晃动不能再次触发。惯性采样间隔大于20毫秒或传感器失效时清除进度，不把空档计入持续发力。

鼠标原报告优先发送；甩拳只发新事件，每秒一次20字节心跳，电脑每5秒续期一次8字节参数，15秒未续期设备端停用。电脑不轮询状态读取；超过3秒未收到有效心跳则释放并低频重连。配置代号、启动代号、循环序号及设备时钟共同丢弃重复、乱序和迟到数据；迟到心跳也不能刷新旧动作的新鲜度。

## 验证边界

自动检查使用隔离配置和模拟输出，覆盖统一选键、参数保存和失败补存、总开关、未绑定、解绑、切模式、来源释放、重复通知、设备重启、序号与毫秒回绕、积压心跳及通知。浏览器使用实际页面模块和原选键控件，不向系统或游戏发送测试键。

设备侧合成样本和编译不能替代真人甩动验收。不同握法的灵敏度、回弹过滤实效、游戏收到的按键及开启拳击后鼠标手感，需要设备开机并更新接口固件后实测。纯电池计数清零的原因仍未定位，不能作为丢键证据，也不归因于本次甩拳改动。

## 网站调节

现有[枪型飞鼠控制页](https://guiwu-aware.icu/ota-admin/gunmouse.html)增加甩拳设置和本轮计数。点“连接甩拳控制”后，通过本机软件读取、保存同一份参数，不另外写设备参数或建立第二个甩拳蓝牙连接。原有方向、触摸、摇杆等设备控制继续使用原网页蓝牙入口。

网站只获得本机三个飞鼠接口的读写权限；精确限制主站来源和浏览器预检，不给网站开放输出总开关、绑定编辑、摄像头或其它接口。网站页面的连接策略仅为此页增加本机地址。需要 Windows 的 Edge 或 Chrome 允许页面访问本地网络，本机 MotionControl 需保持运行。读取状态每秒一次，隐藏页面停止请求；更改未保存时状态刷新不覆盖输入，保存失败使用软件已有的补存回执。

2026-10-27后续：实机已通过双分区无线更新至3.3.0，程序构建身份与文件一致，常开、摇杆停用及原校准逐项保留。MotionControl 已接收有效心跳，用户做过少量甩动验证；样本不足以宣称准确率。用户随后选择在网站自行调节，停止引导动作测试。当前参数以网站及软件实时读回为准，按键仍默认不绑定。

### 连接恢复

软件先检查 Windows 实际提供的管理接口，再读取设备身份。接口暂缺时释放本次管理会话，间隔5秒在直接发现与系统保存的接口表之间切换重试；只有从设备读到明确旧版本时才提示升级，不把一次不完整发现当作旧固件。断线回调立即清除就绪、释放本来源按键；旧会话回调不能改写新连接。保留原通知及续期频率，不扫描或高频查询传感器。

网站将“配置已保存”与“设备已就绪”分别显示。设备状态只展示简短中文，连接说明显示等待、自动重连及最近有效心跳；参数须由设备确认并接收有效心跳后才显示就绪。本机软件重启后按实例身份重新接收配置版本与本轮基线。
