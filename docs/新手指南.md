# 新手指南

从下载到能玩，大约十分钟。这里只讲第一次要做的事。

---

## 你需要

| | 说明 |
|---|---|
| **Windows 电脑** | 虚拟手柄驱动只有 Windows 版 |
| **一个摄像头** | 笔记本自带的就行 |
| **两米见方的空地** | 这是站着玩的，坐着不行 |

Android 手机是可选的，只在笔记本摄像头拍不全你的身体时才需要。

---

## 第一步　装驱动

双击 **`安装虚拟手柄驱动.exe`**，装完可能要重启。每台电脑只装一次。

**不能跳过。** 不装的话，你做动作时界面上区域会亮，但游戏里没有任何反应。

> 驱动是开源的 [ViGEmBus](https://github.com/nefarius/ViGEmBus/releases)，作用是模拟出一个 Xbox 手柄。包里带的是官方原版。

---

## 第二步　启动

双击 **`启动.bat`**。弹出的黑框**不要关**，它就是软件本身。

浏览器会自动打开 `http://127.0.0.1:8766`。没自动开就手动粘贴这个地址。

![三个标签页](images/01-三个标签页.png)

| 标签页 | 放什么 |
|---|---|
| **开始** | 看画面、校准、开始控制。第一次主要用这页 |
| **本游戏** | 只影响当前游戏的按键映射 |
| **通用设置** | 所有游戏共用：设备、手感、语音 |

---

## 第三步　跟着「开始前检查」走

右边这个清单会告诉你卡在哪一步，每一步都有按钮直接跳过去。

![开始前检查](images/02-开始前检查.png)

### 1　设备

- **摄像头** 绿色 = 找到摄像头
- **人体** 绿色 = **现在正看见你**；灰色说明画面里没人或拍不全
- **手机未连接** 不用手机就不用管

「人体」是灰的时候，左边画面会提示：

![还没看到人](images/03-还没看到人.png)

站到摄像头前，让**头和两个肩膀**都进画面。要用踏步、抬腿这类动作的话，脚也得拍得到——通常意味着退后到两米外，或把摄像头架高。

### 2　游戏

点「换游戏」搜你要玩的那个。

![选游戏](images/05-选游戏.png)

内置约 200 个配置，但**绝大多数是自动生成的，没有人真的玩过**，界面上标着「实验配置」。不好用是正常的，在「本游戏」页可以自己改，改完自动保存。标「已验证」的才实际跑通过。

搜不到你的游戏就随便选一个再自己改。

### 3　校准

点「站好并校准」，或者直接说 **"开始校准"**。

它记住你此刻的位置和朝向当作"正前方"，之后的动作都相对这个基准算。校准时**站好、看向屏幕中心、别乱动**。

校准一次就记住了，下次打开直接用（清单上写「沿用上次校准」）。换了站的位置、挪了摄像头，再点一次就行。

### 4　开始

点最上方蓝色的「**开始游戏控制**」。从这一刻起你的动作变成游戏输入，切到游戏就能玩。

> **随时按 `F9` 紧急停止。** 识别抽风、鼠标乱飞时，这个键立刻切断所有输出。

### 不用开游戏就能试：握拳动鼠标

默认开着**手控鼠标**。伸出右手握拳，桌面上的鼠标指针跟着你的手走，松开就停，
再握一次从当前位置重新开始——像把鼠标提起来放一下。

不用打开任何游戏，这是确认"装好了、也认得出我"最快的办法。

握拳期间右手那边的区域按键会暂停，免得一边移鼠标一边乱按。

---

## 鼠标和手柄不要混着用

一台电脑同一时间只认一套输入设备。软件默认全走**鼠标**：「通用设置 → 游戏输出
→ 视角输出」是「鼠标视角」。

但内置的游戏方案大多绑的是 **Xbox 按键**。两种混着出，游戏会在手柄提示和键鼠
提示之间反复横跳：画面上的按键图标一会儿是「A」一会儿是鼠标图标。

所以要么全鼠标键盘，要么全 Xbox：

- **想用握拳直接控鼠标** —— 视角输出保持「鼠标视角」，再去「本游戏」页把那些
  Xbox 按键换成键盘或鼠标按键。
- **要玩手柄游戏** —— 把视角输出改成「Xbox 360 右摇杆」。注意这时候**握拳推的
  是右摇杆，桌面上的鼠标不会动**，这不是坏了。

混着的时候，「通用设置 → 游戏输出」下面会出现一行橙色提示，写清楚还有几个动作
出的是 Xbox 按键。

---

## 画面里的框是什么

![跟随你的区域](images/06-跟随你的区域.png)

| 框 | 位置 | 触发方式 |
|---|---|---|
| **Y** | 左手边 | 左手伸进去 |
| **B** | 右手边 | 右手伸进去 |
| **头顶跳跃** | 头顶 | 手举过头顶 |
| **LB / RB** | 左右脚边 | 抬脚踩进去 |

**框亮 = 这个键正被按下。** 这是判断"它到底认没认出来"最直接的办法：先看框亮不亮，再去游戏里看反应。

框跟着你的身体走，在房间里走动不用重新对位。按键绑成什么在「本游戏」页改。

想让框不跟着走：点实时画面上的「**挪动区域**」，框就定在现在的位置。定住后直接拖框改位置、拖框四个角改大小（点一下选中后，方向键移动，按住 Shift 再按方向键改大小），点「保存区域」。定住会一直记着，重启也在；想让它重新跟着你走，点「**恢复跟随**」。也可以不碰鼠标：在「本游戏」的映射表里把某个区域、动作或口令的输出类型选成「**系统功能 → 定住区域 / 恢复跟随**」。

进框之后多快按下，在「通用设置 → 区域触发方式」里选：「防误触」（默认）要手伸进去够深、停一小会儿才按；「进去就按」进框那一帧就按、出框就松，反应最快，也最容易误按。

框够不着，或者站着不动也会碰到：「通用设置 → 量身 → 量一下」。站到平时玩的位置，照提示两手往两边挥一挥、左右脚各往外伸一下、原地跳一下，框就照你自己的动作放。开着握拳控制的话，最后还会让你张开手、握紧手各一次，握拳就按你的手来认。量一次就记住了，想回到原来的大小点「区域恢复默认大小」。

没绑键的动作做了也不会亮——框、手机头顶、映射表都不显示。想确认它认没认出来，去「动作测试」页。

## 手机当摄像头（可选）

笔记本摄像头拍不全身体时用。**不用注册，也不用配对**：

1. 手机上装好 APK（网盘包里的「手机端」文件夹）
2. 电脑这边「通用设置 → 输入来源」，摄像头来源选「**手机摄像头**」，点「连接并开始识别」
3. 手机上打开 MotionControl，选「**固定摄像头**」
4. 点「**连接并开始**」。**地址不用自己填**，它会自己找到电脑
5. 手机架在你正前方，人站进画面

![输入来源](images/04-输入来源.png)

手机右上角变成绿色的「已连接电脑」就成了。

**第一次会慢**：要给摄像头权限、加载识别模型，还要自己把电脑找出来，几十秒都算正常。
之后它记住了地址，实测**五秒左右**就连上。别急着重按。

**两种连法，二选一：**

- **同一个 WiFi** —— 手机和电脑连同一个路由器，这是最省事的。
- **插数据线** —— 还要在手机上打开「**USB 网络共享**」（系统设置里搜"网络共享"）。
  延迟更低，但打开之后电脑上网走的是手机流量。只插线不开网络共享是连不上的。

手机端**本地识别**，只把关键点坐标发给电脑，**画面不出手机**。

## 出问题了

### 动作认出来了，游戏里没反应

八成是**驱动没装**。做动作时看框亮不亮：亮了说明识别没问题，问题在输出。

也可能是游戏本身要在设置里手动切到手柄模式。

### 「人体」一直是灰的

退后一点让头和双肩入镜；别逆光；太暗就开灯。

### 电脑上有好几个摄像头，用的不是我想要的那个

「通用设置 → 输入来源 → 用哪个摄像头」点「**扫描摄像头**」，换一个再点「连接并
开始识别」，看画面里是不是你。外接摄像头、采集卡、OBS 虚拟摄像头都会占一个序号，
排在前面的未必是对着你的那个。

### 这台电脑根本没有摄像头

把「摄像头来源」改成「**手机摄像头**」，按下面那节用手机。**改一次就记住了**，
下次打开还是手机。

### 手机连不上

**先看手机那一页**：它会直接说缺什么——数据线通没通、在不在 WiFi 上、还是两条
路都没开。橙色那种情况旁边有按钮，一下跳到系统对应的设置页。

两条路都没开是最常见的：插了线但没在手机上打开「USB 网络共享」，而 WiFi 又不是
电脑那个。二选一开一个就行。

还有一个原因手机看不出来：**Windows 防火墙**第一次会弹窗，**要点允许**。当时点
了拒绝的话，手机会一直连不上而且两边都看不出原因——去防火墙设置里删掉 Python
的规则，重启程序再试。

电脑那边「通用设置 → 手机连不上怎么办」里也有一行，写着数据线这头通没通。

### 鼠标乱飞 / 视角一直转

按 **F9**，然后在「通用设置 → 手感」调灵敏度和中心死区。

### 我想用抬手转上下视角

默认是**关**的：它抢的是右手，而握拳控鼠标用的也是右手，两个一起开会打架。

要用的话去「通用设置 → 视角 → 上下视角控制」选「右手」，画面上会多一个绿框——
左手伸进绿框，右手抬高放低就是上下看。这时候建议把手控鼠标关掉。

## 设置存在哪

```
%LOCALAPPDATA%\MotionControl\
```

复制这一行粘到文件管理器地址栏就能打开。按键映射、自定义动作、语音口令、校准数据都在这里，**不在程序文件夹里**。

所以程序文件夹可以随便挪、随便改名；但拷到另一台电脑，设置**不会**跟着走。换电脑、换摄像头、或摄像头挪了位置，都要重新校准。
