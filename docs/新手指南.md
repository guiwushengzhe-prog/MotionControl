# 新手指南

第一次用，从下载到能玩，大概十分钟。

这份指南只讲第一次要做的事。调参数、自定义动作、语音口令那些，等你先玩起来了再说。

---

## 开始之前，先确认三件事

| | 必须吗 | 说明 |
|---|---|---|
| **Windows 电脑** | 是 | 虚拟手柄驱动只有 Windows 版，Mac 和 Linux 暂时用不了 |
| **一个摄像头** | 是 | 笔记本自带的就行。如果拍不全你的身体，可以改用手机当摄像头 |
| **一块能站的地方** | 是 | 大约两米见方。你要真的站起来动 |
| Android 手机 | 否 | 只在你需要"把摄像头架远一点"时才用 |

还有一件事要有心理准备：**这是站着玩的**。你得离开椅子，站到摄像头能拍到你上半身的地方。坐着不行。

---

## 第一步　装虚拟手柄驱动

解压下载的压缩包，双击 **`安装虚拟手柄驱动.exe`**，按提示装完，可能要重启电脑。

**这一步不能跳过。** 不装的话，所有手柄按键、摇杆都不会有反应——你做动作，画面上区域会亮，但游戏里什么都不发生。这是最常见的"我照做了但没用"。

每台电脑只需要装一次。

> 这个驱动叫 ViGEmBus，是一个开源项目（[官方地址](https://github.com/nefarius/ViGEmBus/releases)），作用是让程序能模拟出一个 Xbox 手柄。压缩包里带的是官方原版，没有改动过。

---

## 第二步　启动

双击 **`启动.bat`**。

会弹出一个黑色的命令行窗口——**不要关它，它就是程序本身**。关掉黑框等于关掉软件。

然后浏览器打开：

```
http://127.0.0.1:8766
```

（通常会自动打开。没自动打开的话，手动把这个地址粘进浏览器。）

界面长这样，上面有三个标签页：

![三个标签页](images/01-三个标签页.png)

| 标签页 | 放什么 |
|---|---|
| **开始** | 看画面、校准、开始控制。第一次用主要在这一页 |
| **本游戏** | 只影响当前游戏：按键映射、自定义动作 |
| **通用设置** | 所有游戏共用：设备、手感、语音 |

---

## 第三步　跟着「开始前检查」走

「开始」这一页的右边有一个清单，它会告诉你现在卡在哪一步：

![开始前检查](images/02-开始前检查.png)

四步按顺序做，每一步右边都有按钮直接跳过去。

### 1　设备

三个小标签的意思：

- **摄像头** — 绿色表示找到摄像头了
- **人体** — 绿色表示**现在正看见你**。灰色说明画面里没人或者拍不全
- **手机未连接** — 不用手机的话，这个可以一直是灰的

如果「人体」是灰的，左边画面会写着提示：

![还没看到人](images/03-还没看到人.png)

> **请让头部和双肩入镜；脚部动作需要脚部入镜**

站到摄像头前，让头和两个肩膀都进画面。想用踏步、抬腿这类动作的话，脚也得能拍到——这通常意味着你要退后到两米以外，或者把摄像头架高一点。

### 2　游戏

内置了约 200 个游戏的配置。点「换游戏」搜你要玩的那个：

![选游戏](images/05-选游戏.png)

**关于「实验配置」这个标记**，得说实话：这两百个里绝大多数是根据公开的手柄配置自动生成的，**没有人真的玩过**。不好用是正常的，你可以在「本游戏」那一页自己改，改完自动保存。标着「已验证」的才是实际跑通过的。

搜不到你的游戏也没关系，随便选一个再自己改映射。

### 3　校准

点「站好并校准」，或者直接说 **"开始校准"**。

校准做的事是：记住你现在站的位置和朝向，当作"正前方"。之后你转头、抬手，都是相对这个基准算的。

**校准的时候站好、看向游戏屏幕中心、保持自然姿势**，别乱动。

### 4　开始

点最上方那个蓝色的「**开始游戏控制**」。

从这一刻起，你的动作会真的变成手柄输入。切到游戏窗口就能玩了。

> **随时按 `F9` 紧急停止。** 记住这个键——识别抽风、鼠标乱飞的时候，F9 立刻切断所有输出。

## 画面里那些框是什么

开始之后，左边画面会出现几个彩色的框，跟着你的身体走：

![跟随你的区域](images/06-跟随你的区域.png)

| 框 | 位置 | 默认触发 |
|---|---|---|
| **Y** | 左手边 | 左手伸进去 |
| **B** | 右手边 | 右手伸进去 |
| **头顶跳跃** | 头顶上方 | 手举过头顶 |
| **LB / RB** | 左右脚边 | 抬脚踩进去 |

**框亮起来 = 这个键正被按下。** 这是你判断"它到底认没认出来"最直接的方式——先看框亮不亮，再去游戏里看有没有反应。

这些框跟着你的身体移动，所以你在房间里走动也不用重新对位。

按键绑成什么，在「本游戏」那一页可以改。

## 手机当摄像头（可选）

笔记本摄像头拍不全身体的话，用手机：装上 APK，和电脑连**同一个网络**，在「通用设置 → 输入来源」里把摄像头来源改成「手机摄像头」：

![输入来源](images/04-输入来源.png)

首次要配对一次：网页上点「配对新设备」拿到一个 8 位码，在手机上填进去，2 分钟内有效。配对之后电脑会记住这台手机，以后直接连。

手机端是**本地识别**的——它自己算出关键点坐标，只把坐标发给电脑，**画面不出手机**。

插数据线也能连，而且不需要打开 USB 调试。

## 出问题了

### 动作认出来了，游戏里没反应

**八成是虚拟手柄驱动没装**（第一步）。判断方法：做动作时看画面上的框亮不亮。框亮了说明识别没问题，问题在输出。

也可能是游戏本身不读手柄输入——有些游戏要在设置里手动切换到手柄模式。

### 「人体」一直是灰的

- 退后一点，让头和双肩完整入镜
- 背后别太亮（逆光会拍不清）
- 开个灯，太暗认不出来

### 手机连不上

- 确认手机和电脑**在同一个 WiFi** 下
- 网页「通用设置」里展开「手机连不上怎么办」，里面列着所有可用地址，挑一个填到手机上
- Windows 防火墙第一次可能会弹窗问是否允许，要点**允许**。如果当时手滑点了拒绝，手机就一直连不上，这种情况在防火墙设置里把 Python 的规则删掉再重启一次程序

### 鼠标乱飞 / 视角一直转

按 **F9**。然后回到「通用设置 → 手感」调灵敏度和中心死区。

### 我用手控鼠标转视角，画面里那个绿色的「上下视角」框是干嘛的

用不着，关掉就行。「通用设置 → 视角 → 上下视角控制」选「关闭」，绿框就不出现了。

界面上也会提示你这一点。

---

## 你的设置存在哪

```
%LOCALAPPDATA%\MotionControl\
```

（复制这一行粘到文件管理器地址栏就能打开。）

按键映射、自定义动作、语音口令、校准数据都在这里，**不在程序文件夹里**。所以：

- 程序文件夹可以随便挪位置、改名字
- 但把它拷到另一台电脑，设置**不会**跟着走
- 换电脑、换摄像头、或者摄像头挪了位置，都要重新校准一次
