# 新手免鼠标视角试调

入口在“设置 → 体感 → 新手试调”，新手教学的“想学哪个”菜单也能进入。游戏输出已移到体感页面，和视角手感放在一起。

## 操作

1. 打开后暂停控制，保留摄像头当前选择和运行状态。先看向屏幕保持自然姿势，记录菜单的临时中心；不会重新写入个人校准。
2. 用左右转头或左右侧倾选择大卡片，回正停留约0.9秒确认。菜单方式可切换，也能反转选择方向。选择转头、头部侧倾、右手握拳或左手握拳后，保存该左右视角方案，上下来源保留。
3. 调速阶段：左侧逐格减慢，右侧逐格加快。小于8度不移动，8度慢档、15度中档、24度快档，重复间隔约0.70、0.35、0.16秒。每次只走一个刻度，卡帧不会补跳；回正停止变化并停留确认。
4. 确认速度后保存，再进入独立10秒试用场景。试用阶段动作只移动预览，不操作菜单。试完选择再调、完成、校准正前方或更换方式。握拳调速修改的是握拳灵敏度，头部调速只修改头部左右速度。

打开或关闭试调不会自动开始识别或恢复系统控制。选定方式及确认速度时保存，关闭保留已应用的设置；未确认的速度刻度不保存。断帧、丢脸或页面隐藏时清除待确认状态，恢复后重新回正。键盘方向键、回车和鼠标仍可使用。

旧骨骼转头输出比例值时，菜单沿用控制器0.34比例对应18度的参考尺度，并标注“菜单等效角度”；它只用于选项移动，不冒充模型测得的实际转头角度，也不改变游戏转向算法。

## 真实合成指标

头部和握拳分别接管被分配的方向，不能彼此相乘。每路归一化输出进入原有输出后端：

- 鼠标：输入先限在正负2，再乘水平/垂直移动计数速度；单位为系统相对鼠标移动计数/秒。
- 右摇杆：输入先限在正负1，再乘游戏倍率，最后限制在满杆正负100%。提高已经满杆的倍率，会使较小动作更早达到满杆，不能超过满杆。
- 握拳灵敏度在手控环节先限到满幅。上下视角由自己的来源和灵敏度计算。

例如输出倍率250%、头部左右100%、握拳40%，水平鼠标上限分别为1500与600计数/秒；手柄两路在最大动作时均可到100%推杆。不能把100%、40%和250%三者相乘。界面中的游戏内转向速度还受游戏自己的灵敏度和加速设置影响；预览场景不是游戏角度测量。

## 核对范围

合成轨迹验证三档逐格导航和回正确认；隔离浏览器验证实际模块的选卡、保存、失败、头部/手部独立设置、移动布局和输出保持暂停。没有用自动化进行真人操作或真实游戏控制。
