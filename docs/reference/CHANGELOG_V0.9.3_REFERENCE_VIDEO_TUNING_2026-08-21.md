# MotionControl v0.9.3 — Reference Video Tuned Calibration

基线：v0.9.2 forgiving calibration。

## 本轮输入

使用用户提供的 12.433 秒、720×1280、30 FPS 站立正视视频做视觉稳定性检查，并结合同一运行链路页面显示的约 16.74 pose FPS 调整校准默认时序。

## 改动

- 保留“不要要求绝对静止”的原则。
- 语音后准备仍为 1.0 秒。
- 固定 2.8 秒结束改为“时间 + 样本数”双条件：至少 2.2 秒且达到 32 个有效样本才正常完成。
- 墙钟上限由 6.5 秒缩到 6.0 秒。
- 墙钟到期的最低可成功样本由 24 调整为 20，避免低 FPS 下明明有足够稳健样本却失败。
- 校准进度 UI 同时显示秒数和有效样本目标；进度条只有时间与样本都满足时才到 100%。
- 加入参考视频手机节奏回归测试，覆盖约 16.74 FPS、普通抖动、偶发无效帧和明显跳点。
- 不硬编码参考视频的中心 yaw/pitch；每次运行仍需在实际游戏位置看向屏幕完成语音校准。
- 不从视频像素运动伪造 PnP 角度，所以 18°/12° 信号跨度、灵敏度和基础 deadzone 0.10 不因该视频被无依据改动；effective deadzone 继续由真人校准的真实 PnP 噪声自动计算。
