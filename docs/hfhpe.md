# HFHPE 左右转头实验

## 接入方式

“左右转头（实验）”使用 HFHPE 模型从彩色头部图像预测左右转头角度。它复用 MotionControl 已有身体识别结果来定位并裁剪头部，复用当前图像帧，不另开摄像头，也不额外运行整头检测模型。身体骨骼只负责定位，左右角度来自实际模型推理，不由五官位置差换算。不要求深度图。

上游整头检测加姿态的完整演示，与本项目复用已有身体定位的路径有区别。大侧脸、背头或遮挡时，已有身体识别可能先失去头部位置；模型本身支持大角度，并不能保证定位链也始终可靠。头部定位或模型结果失效时停止实验转向，不继续沿用无限期的旧角度。

## 下载模型

在项目目录运行以下命令。默认只下载 128 像素姿态模型，存到 `models/hfhpe`，不会下载教师模型、训练数据或额外整头检测器：

```powershell
python tools/download_hfhpe_models.py
```

下载三种模型供离线对比（当前界面默认采用 128 像素版，不另加一组模型选项）：

```powershell
python tools/download_hfhpe_models.py --model vitt128 vitt64 hgnet64
```

指定存放目录：

```powershell
python tools/download_hfhpe_models.py --output "$env:LOCALAPPDATA\MotionControl\models\hfhpe" --model vitt128
```

程序依次查找项目内的 `models/hfhpe` 和本机用户目录中的 `models/hfhpe`。只在选中实验方式时加载；切走即释放。下载其他候选文件不会自动替换当前模型。

已有正确文件会先核验再复用。新下载先写 `.partial` 临时文件，大小及 SHA256（文件内容校验值）均匹配后才替换；解压只读指定模型成员，不展开压缩包路径，不执行上游脚本。发布标签可能被上游更新，因此标签地址之外还固定了包和模型各自的校验值，内容变化会明确失败，不悄悄换版。

可选的 `--with-detector` 仅供研究上游完整链路，实验控制本身不使用它。指定的轻量检测文件已确认仅保留框分支，无需再剪枝，也无需为下载工具安装额外模型编辑依赖。

## 上游契约

本次研究固定提交为 `6c0cab8cc8e5586f4126ae9a7d30971e08016291`。依据：[官方推理演示](https://github.com/PINTO0309/High-Angle_Robust_Fast_Head_Pose_Estimation/blob/6c0cab8cc8e5586f4126ae9a7d30971e08016291/demo/demo_hfhpe_onnx.py)、[导出脚本](https://github.com/PINTO0309/High-Angle_Robust_Fast_Head_Pose_Estimation/blob/6c0cab8cc8e5586f4126ae9a7d30971e08016291/scripts/export_hfhpe.py)、[权重发布](https://github.com/PINTO0309/High-Angle_Robust_Fast_Head_Pose_Estimation/releases/tag/weights)。

- 整头框每边扩展 5%，取长边正方形，靠近画面边缘时平移入画。原画面尺寸小于所需方框时，裁后居中补黑至正方形。
- 缩小时用面积插值，放大时用兰佐斯四阶插值。通道从蓝绿红转为红绿蓝，单精度浮点数按 `像素/127.5−1` 归一化，排列为“批次、通道、高、宽”。
- 输入名 `images`；本次用的固定单张模型输入为 `[1,3,128,128]` 或 `[1,3,64,64]`。上游另有可变批次版本，当前单人控制无需使用。
- 输出 `cos_sin` 为六个数：左右转头、抬低头、侧倾各自的余弦与正弦。用 `atan2(正弦,余弦)` 解码，再换算为度。
- 上游左右角度 0° 为正脸，90° 朝观察者左侧，180° 为背头，270° 朝观察者右侧。控制端需要取有符号角度并围绕校准中心计算圆周差，避免跨越 0° 时跳变。
- 输出 `kappa` 是三个角度各自的集中度，越大通常越有把握，约为 0.001 至 100；它不是 0 至 1 的成功概率，也不是经过本项目真人数据校准的误差界限。
- 所选模型内部已包含侧倾估计、去侧倾变换和转头估计。带 `rollgate` 的版本在侧倾把握较低时减弱内部去侧倾；输出角度仍是原始估计，不能把此门控当作整个转向链的可靠性保证。

## 本机实测

2026-10-17，英特尔 i7-14650HX，推理运行库 1.23.2，处理器两个计算线程、一个调度线程，预热 10 次后各测 60 次。三个模型均采用上游演示相同的裁剪与解码，对同一幅 NASA 宇航员图、同一整头框计算；没有连接用户摄像头。

| 模型 | 模型文件大小 | 纯推理中位数 | 纯推理第 95 百分位 | 含裁剪中位数 | 含裁剪第 95 百分位 | 左右角度输出 |
|---|---:|---:|---:|---:|---:|---:|
| ViT-T，128 像素 | 25,764,719 字节 | 7.45 毫秒 | 8.42 毫秒 | 8.17 毫秒 | 10.60 毫秒 | −6.04° |
| ViT-T，64 像素 | 25,641,823 字节 | 3.22 毫秒 | 4.23 毫秒 | 3.26 毫秒 | 4.05 毫秒 | −5.16° |
| HGNetV2，64 像素 | 10,573,002 字节 | 1.49 毫秒 | 1.92 毫秒 | 1.68 毫秒 | 2.95 毫秒 | −2.37° |

这些数字只说明当前机器上的模型执行成本与输出差异。示例图没有精确姿态真值，不能据此比较准确率，也不代表用户摄像头、大侧脸或游戏控制的实测结果。上游表格中的角度误差来自其训练分布选择指标，不作为本项目真人精度承诺。

为对照才单独运行的轻量整头检测器约需 217 毫秒，远高于三种姿态模型，因此当前实验路径复用已有身体定位。此检测器未加入默认运行链。

另在正式后台使用的 Python 环境上，以同一张图片实际执行“身体识别→复用定位裁头→三种 HFHPE”整条路径，三种均返回有效角度。128 像素版含裁剪中位数为 8.04 毫秒，第 95 百分位为 9.02 毫秒（预热 5 次、测量 30 次）；这部分是已有身体识别之后新增的工作，不再运行前述整头检测器。骨骼粗框会留出颅顶、头发和后脑，与上游独立检测框仍有差异；这里只选模型和核实接线，不据一张图片宣称真人精度达标。

测试图采用 scikit-image 官方提供的 NASA 宇航员 Eileen Collins 图，其[官方说明](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut)标明为公有领域。图片和下载压缩包只用于本机研究，不加入仓库。
