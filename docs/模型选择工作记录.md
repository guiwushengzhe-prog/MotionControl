# 模型选择工作记录

## 2026-10-08：电脑按性能选模型、手机可接收高精度模型

- 电脑基线：0582149；分支 codex/pose-model-selection-20261008。
- 身体识别设置增加自动、完整（Full）、高精度（Heavy）三项，保存上次选择。
- 自动模式先用 Heavy，在有人、手势加载结束的实际识别帧上预热三帧，再用 24 帧的九十分位耗时与当前实际采集帧距比较；超出九成帧预算就改用 Full，保持识别响应优先。空场景不作为选型依据。
- 两种身体模型均可正常加载。只在内存读取当前预览的一帧、以静态图像模式重复识别的测量：Full 平均 21.16 毫秒、Heavy 平均 57.99 毫秒。这是单帧耗时，不是最终动态识别帧率，也不是显卡性能结论。
- 当前 Windows 原生识别链使用处理器；电脑显卡足够强不表示这条链能自动使用它。
- 原生手势模型沿用已配置手控方向的请求，创建 MediaPipe Gesture Recognizer；按身体手腕裁图，返回同一坐标中的 21 个手部关节点给现有握拳算法。无需手控时关闭识别器，不改变原有动作映射或握拳阈值。
- 模型目录支持发布包自己的 models/mediapipe；开发时还可找到模型库 runtime 下的既有手势资源。固定的 mp-full 分享路由始终分享 Full，不随当前电脑选中 Heavy 而变。
- “发送给手机”只给已连接手机发送模型信息和校验值，经现有设备连接下载；不改变手机模型选择。模型文件接口沿用现有设备口，增加与模型清单一致的跨域读取头。
- 手机配套分支 codex/phone-model-selection-20261008，以已下载的 github/main（fabbd77）为基线，安装包版本 2.4.1。
- 电脑设置与手机选择独立。旧手机仍能使用既有控制配置；新版手机收到 Heavy 后才显示选择入口，默认继续 Full。
