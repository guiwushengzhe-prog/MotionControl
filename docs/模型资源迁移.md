# 模型文件与运行环境迁移

实验与诊断的“模型文件与运行环境”默认收起，列出缺失的运行程序、源码、权重、个人倾角读出、扩展库及配套文件。普通状态刷新只缓存登记内容和文件状态，不重新计算模型摘要或启动模型。

保持依赖目录的相对结构，搬动后选择新的依赖根目录，点击“检查并更新位置”。先核对原登记的权重和个人读出摘要，再仅用处理器试加载同一个工作进程；全部通过后才一起保存登记与最近有效副本。第一次通过时建立配套文件摘要，以后同一版本迁移逐项核对。模型目录与运行环境分盘时可以只迁移模型目录，未搬动的运行环境沿用原位置。

取消、文件不符、运行环境不完整、保存失败或检查期间开始游戏控制，都保留原登记。游戏控制开启时先暂停，再检查。检查不采集画面或执行按键。外部准备工具重新登记模型后，后台沿用现有状态刷新发现版本变化，清空旧倾角结果并重新加载；逐帧提交不读文件。

完整配置备份包含登记及其有效副本，但不包含第三方模型、解释器、扩展库或私人训练原始资料。新电脑需先准备匹配的外部运行环境，再重新定位；跨电脑恢复保留目标电脑的模型登记。不要只修改显示路径或用同名文件冒充原模型。

维护时，个人模型准备工具也使用共用的配置事务与有效副本。正式登记新权重或读出会清除旧迁移摘要，下一次完整检查建立新版本的摘要。

验证边界：隔离配置检查覆盖缺件、损坏登记恢复、失败回退、迟到检查、外部更新、页面草稿及取消；另复制真实模型文件并实际移动副本，完成两次处理器试加载，原模型和用户配置未改动。解释器和扩展库沿用原位置，未据此宣称整个解释器目录可直接搬动。游戏内效果及新的真人动作精度需另行验收。
