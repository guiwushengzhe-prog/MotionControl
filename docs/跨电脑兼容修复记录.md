# 跨电脑兼容修复记录

## 2026-11-17：复现与修复范围

- 用户反馈安装包换电脑后后台或摄像头无法正常工作，未收到对方的具体报错；先完成全面审查，再按用户要求直接修复确认的问题。
- 正式安装包对应提交 `adde680`，本次在独立分支 `codex/compatibility-fixes-20261117` 修复。用户要求合并后删除临时分支、工作目录和中间构建文件，保留最终安装包。
- 同一人体模型在中文路径下用文件路径加载失败，用文件内容加载成功；已统一标准模型、优化模型回退的加载方式。
- 初始化持有相机锁及来源切换锁时，状态和停止会一起等待；耗时初始化移出相机状态锁，状态快照不再等待来源切换操作，停止有真实期限，取消后的初始化不发布新会话。
- 系统真实枚举结果不再受数字盲探上限限制；数字盲探仍有范围，选择与恢复允许系统返回的后续序号。
- 本机管理写入统一检查来源，保留已授权飞鼠门户的专用检查；退出仅接受写入请求。隔离复现使用替代输出，没有触发真实输出或停止正式后台。
- 录制设置保存队列保留未确认修改，后一次保存包含前一次失败的项目；中文输入、菜单键盘及语音控件名称按 Modern Web Guidance 的输入法与无障碍规则修复。
- 故障诊断由原生入口导出已知启动日志的有限尾部，不读取账户、配对或个人配置文件，并隐去常见凭据字段；无需后台或解释器运行。识别诊断新增固定错误编号，避免只剩“有错误”的状态。
- 诊断思路参考既有便携分支的独立诊断能力，本次直接适配现有安装入口，没有引入便携运行和资料快照系统。

## 验证边界

- 设备检查使用替代设备和临时用户目录；真实中文模型加载单独核对，不打开个人摄像头、麦克风或游戏输出。
- 新增复现覆盖中文模型路径及优化回退、设备初始化阻塞、停止期限、后续设备序号、外站写入拒绝、读取退出无副作用、录制保存失败后重试、中文选字回车、菜单键盘及脱离后台的故障诊断。
- 最终仍需对方电脑的实机反馈才能确认其原始故障完全消失；本机验证不会标成另一台电脑验收。

## 网页规范采用

- `ime-safe-enter-submit`：组合输入和兼容键值都抑制提交，采用规则“event.isComposing || event.keyCode === 229”，避免确认中文选字时添加半截游戏名。
- `menu`：补齐进入菜单、方向键、首尾项、退出和焦点回归；原生焦点组不可用时提供本地兼容操作，遵循“Never install it when native focusgroup is present”。
- `accessibility`：把语音映射中的现有文字关联为实际控件名称，遵循“Provide a label for all form controls”，无需新增说明性小字。
- `security`：管理面核对来源、主机与浏览器请求来源标记，落实“reject suspicious cross-site requests”，同时保留已明确授权的门户与模型分享场景。

## 2026-11-18：电脑端首次使用走查

- 实际从开始页进入设备设置，从“添加设备”选择手机后，二维码底部落到 1280 × 850 窗口外。扫码与切换摄像头原来分属两张设备卡片。开始页、手机卡片和添加入口现使用同一居中窗口，扫码时可在原位选择“用手机摄像头”。若电脑仍在用本机镜头，设备卡片区分手机已有输入和当前正在使用的来源。
- 进入设置时由状态自动打开弹窗会挡住运动记录等操作。现在只有主动点击连接或首次主动选择手机来源时才打开，轮询只更新状态。心率入口保留在原页面，不显示切换摄像头的操作。原“下次自动连接”已移除。
- 录制页的画幅和分辨率已分开。选游戏时英语关键词 Wukong 可查到，中文“悟空”还不能命中现有名称。按键从手柄切到键盘时，未输入键位只提示下一步，填完后仍自动保存。真正保存失败继续保留重试操作。
- 连接、设备、教学与心率入口 16 项回归通过，按键保存与冲突 3 项通过。连接到达状态在回归中采用替代输入，另核对真实后台生成的二维码和来源切换。
- 依照 Modern Web Guidance 的 `dialog` 指南采用“top-layer rendering and `Esc` handling”，让二维码不受设备卡片滚动影响，关闭后由浏览器恢复焦点。
