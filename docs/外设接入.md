# 设备与外设

在“设置 → 设备与外设”查看连接，点“管理”打开对应设置，或点“添加设备”选择类型。

- 摄像头：接好设备后查找，在原摄像头下拉框中选择。普通摄像头、采集卡与 Kinect 复用已有相机接口。
- 枪型飞鼠：先在 Windows 蓝牙中配对，在添加入口查找并选择，点“连接管理”。原鼠标、触摸和摇杆设置由设备回报，甩拳模式与按键沿用通用设置和本游戏映射。
- 手机：从同一入口打开原扫码连接。
- 麦克风：查找并在原音频输入下拉框中选择。

飞鼠的“鼠标、触摸与摇杆”可以展开或收起，包含常开、方向、灵敏度、触摸门限、摇杆和校准。设备设置读取实际值，操作通过设备执行序号及目标回读确认。校准命令确认表示设备已经开始校准，完成状态仍以设备回报为准。

## 共用连接与配置

`motioncontrol/peripherals.py` 只描述设备类型、设置位置和添加操作按钮，不再保存一份相机、声音或蓝牙配置。页面从目录生成统一入口，连接状态复用原状态刷新。

飞鼠管理请求交给 `GunMouseBridge` 已持有的连接串行处理，管理与甩拳不各开一条蓝牙连接。进入管理页按需读取设备状态，手动刷新或操作时读取确认，不持续轮询传感器。拳击关闭后仍可单独保持管理连接；断开管理连接同时关闭本软件的拳击模式，不解除 Windows 的鼠标配对。

连接偏好和甩拳参数进入既有通用设置及保存回执，设备侧参数使用固件原来的保存机制。同机备份保留连接偏好；跨电脑恢复继续保留目标电脑自己的设备配置。

## 后续添加设备类型

1. 增加设备接入模块，负责发现、连接、状态和操作。设备扫描由用户触发，状态尽量复用已有数据；连接失效时撤销对应输入，排队操作有期限且不在新连接上补发。
2. 在设备目录登记稳定编号、中文名称、`target` 设置区域和 `add_control` 原添加按钮。设置区域使用统一设置行，目录和“添加设备”窗口不再增加设备类型分支。
3. 接入模块通过 `renderPeripheralState` 更新目录中的状态。多台同类设备的选择保留设备自身的稳定标识，不能只以列表序号识别。
4. 如增加 Joy-Con 等动作或按键输入，输入事件进入内核统一映射，复用总开关、无绑定不输出与断线释放。不能把硬件按键直接绕过游戏配置发给系统。
5. 新配置遵循[配置保存与恢复规范](配置保存与恢复规范.md)，新动作遵循[新增动作接入规范](新增动作接入规范.md)。

验证分别核对设备回报、命令确认和游戏接收；模拟页面与模拟设备用于回归检查，不代替实机效果。
