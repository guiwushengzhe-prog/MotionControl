# 单目前后倾个人研究

## 在本机使用

1. 打开“设置 → 实验与诊断”。
2. 确认“单目前后倾模型”为“MocapNET · 处理器个人研究”，再将“前后倾来源”选为“单目前后倾（实验）”。
3. 选择需要的“身体前倾前进”“身体后倾后退”。开始识别后自然站直三秒。
4. 前倾停住持续前进，后倾停住持续后退，回正释放。原来的七度进入、五度释放及控制器平滑继续生效。
5. 可以选择每秒十五帧或三十帧。这里只影响新增前后倾计算，复用已有的人体骨骼点，不额外定位人体，也不生成整张深度图。

初始状态保持关闭。切换来源、丢失身体或停止识别时会释放对应输出。运行状态显示实际模型耗时与画面到结果的时间，这两者不是相同指标。

## Kinect 辅助学习

普通单目摄像头可独立识别前后倾。Kinect 只在开发参考和开启“用Kinect教单目前后倾”时用于学习，不进入模型预测进程。开启学习后需在重设站姿时提供可靠的同人、同步参考，再自然做前倾回正和后倾回正；站直不动只能增加中立样本。

候选读出冻结后，必须用后续动作验证通过才替换当前读出。不能用刚学到的同一批动作证明自己准确。学习数据按摄像头和模型分开，七维深度读出与四十二维骨骼读出不会混用。

## 外部模型与使用范围

此功能提供适配和个人读出接口，仓库不包含 MocapNET 的源码、权重或用户录像。上游文件由用户放入独立目录，保留其许可证；个人研究准备入口为 `tools/prepare_mocap_personal.py`，运行前需已有源代码、上半身模型、独立运行环境和个人倾角读出。

MocapNET 的原许可限制个人非商用研究。商用或再分发需另外处理授权；复制核心代码不能改变原许可。实际适用范围仍取决于个人动作、站位、衣着和骨骼点质量，本机录像评分不代表其他用户或游戏中的验收结果。

之前的三模型深度对比界面已移除，历史保存的对比开关不会在启动后自动继续计算。旧权重与个人录像属于本机研究资料，不由此次界面整理删除或上传。
