- 运动记录由实际控制开关统一通知。手动按钮、系统口令、停止识别与输出异常走同一个状态来源；重复启用不会重置累计基线。开始后自动记录，暂停后继续沿用本次会话，暂停期间可结束本次。不增加自动视频录制。

- 用户确认左右问题发生在画面显示，未确认游戏视角方向有误。底层问题为开始页镜像显示、录制页绘制原图，两条显示路径不一致；本次没有改动采集、骨骼识别、区域命中或头控输出的坐标约定。
- 根据后续截图，在「设备 → 摄像头 → 画面方向」下面放置「镜像画面」。默认开启，保存于现有录制配置。开始页画面、骨骼、区域与悬浮窗使用同一设置；录制与直播共用完成遮脸、抠图和镜像后的处理帧。调整区域时根据显示方向换算回原坐标，文字仍正向显示。
- 录制页可先「选择画面预览」，不创建录制文件；确认后「开始录制」复用所选画面。实际合成预览与录像编码读取同一画布。结束共享或停止录像会释放此页取得的流，不额外打开摄像头。
- 游戏画面和摄像头分别保存裁切范围。编辑完整来源的静态帧，可拖角改变范围、拖框平移、输入四边百分比；取消不写配置，恢复完整画面后仍可重新裁切。人物裁切同步到直播人物网页，游戏画面裁切仅用于本程序合成。
- 保留现有位置、大小与横竖屏控件。「优先选择」改为「选取画面」，提示是浏览器选屏窗口的偏好，最终由用户选择；选屏请求保持直接来自用户点击，避免丢失浏览器要求的点击授权。
