# MotionControl

这是 MotionControl 项目的长期跨会话工程仓库。

## 目的
- 持久化已经确认有净收益的算法脚本、测试与实验结果。
- 保存冻结基线、候选版本、回放工具、依赖锁定信息和跨会话交接文档。
- 新会话优先读取 `docs/HANDOFF.md` 与 `docs/STATUS.md`，不要依赖聊天记录猜测当前状态。
- 任何正式晋级都必须有真人回归数据支持；模拟数据不参与冠军选择。

## 当前核心状态
- 产品回退基线：v160，冻结。
- 当前真人数据净收益候选：v187，冻结，不覆盖。
- v188 safety-first：仅处于候选验证阶段，尚未正式晋级。
- 严格候选顺序：C0 → C1 → C2；前一级未通过不得测试/晋级后一级。

## 仓库约定
- `src/head_control/`：冻结基线和有净收益的头控脚本。
- `tests/`：对应单元/回归测试。
- `docs/HANDOFF.md`：新会话首先阅读的交接文件。
- `docs/STATUS.md`：当前实验状态和下一步。
- `docs/DECISIONS.md`：已经冻结的架构/参数决策。
- `.github/workflows/`：可复现实验和依赖获取流程。
- 原始真人视频优先保存在 Google Drive；仓库记录 Drive ID、哈希、窗口和派生结果，避免把大视频直接塞进 Git 历史。

任何新脚本只有在确认“净收益”后才进入正式 `src/`；失败候选保留在实验记录或独立分支，不覆盖稳定版本。
