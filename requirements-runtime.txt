# Third-party packages the PC app needs at runtime.
#
# The repository had no dependency manifest: the portable release bundles its
# own Python with these already installed, and development installs them by
# hand.  That worked while every dependency was optional-ish -- a missing
# camera library fails loudly at the point of use.  cryptography is the
# exception: without it the update signature check fails quietly, and every
# update is refused as if it were corrupt.
#
# Versions here match what the 2.0 portable bundle actually ships, so this file
# describes reality rather than an aspiration.  Verify with:
#
#   python tools/check_runtime_deps.py
#   python tools/check_runtime_deps.py --bundle "build/release/.../python"

# ECDSA signature check on app updates.  Not optional in a release build --
# see app_update.py.
cryptography>=42.0

# Camera capture and pose inference.
#
# headless 而不是完整版：整个程序只用 core 里的那几个调用（cvtColor、solvePnP、
# findHomography、ORB/BFMatcher、imencode/imdecode、VideoCapture），一次 GUI
# 调用都没有。完整版多出来的 aruco、xfeatures2d、cuda 这些一个都用不上，
# 光 cv2.pyd 就大 26 MB。发布包里还会再删掉 ffmpeg 后端——VideoCapture 只接
# 整数摄像头号和明确指定的 MSMF/DSHOW 后端，从不读视频文件或网络流。
opencv-python-headless>=4.9
numpy>=1.26
mediapipe>=0.10

# Local microphone capture and offline speech recognition.
sounddevice>=0.4.6
vosk>=0.3.45
